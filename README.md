# 智能超声波防撞提示器

《从代码到实物：造你所想》期末 Hackathon 项目

## 项目简介

**一句话定义：** 当障碍物距离小于 30cm 时，LED 自动点亮，提醒用户注意避撞。

**应用场景：** 桌面防撞、盲人辅助导航、倒车提示、智能垃圾桶感应开盖

**产品亮点：** 超低成本、反应灵敏、可扩展性强，完全基于学校提供的开源硬件及耗材完成。

### 引脚分配表

| 元件 | 引脚 | ESP32-C3 | GPIO |
|------|------|----------|------|
| HC-SR04 | VCC | 5V / VIN | - |
| HC-SR04 | GND | GND | - |
| HC-SR04 | Trig | D5 | GPIO 5 |
| HC-SR04 | Echo | D18 | GPIO 18 |
| LED | 正极(+) | 220Ω电阻 → D19 | GPIO 19 |
| LED | 负极(-) | GND | - |

### 接线要点

1. **杜邦线直连**：所有连接使用母对公杜邦线，无需面包板
2. **LED 必须串联电阻**：220Ω 电阻串联在 GPIO6 和 LED 正极之间，防止烧毁
3. **超声波传感器供电**：VCC 接 5V 或 VIN（传感器工作电压为 5V，不能接 3.3V）
4. **Echo 引脚分压**：HC-SR04 的 Echo 输出 5V，ESP32-C3 GPIO 耐受 3.3V。为安全起见，在 Echo 和 GPIO5 之间加分压电路（1kΩ + 2kΩ），将 5V 降到 3.3V

### 分压电路（可选但推荐）

```
HC-SR04 Echo ──── 1kΩ ──┬── ESP32-C3 GPIO5
                        │
                       2kΩ
                        │
                       GND

分压后电压：5V × 2kΩ / (1kΩ + 2kΩ) ≈ 3.3V
```

## 核心代码

```cpp
#define TRIG_PIN  5
#define ECHO_PIN  18
#define LED_PIN   19

void setup() {
  Serial.begin(115200);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  Serial.println("Ultrasonic ready");
}

void loop() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  long duration = pulseIn(ECHO_PIN, HIGH);
  float distance = duration * 0.034 / 2;

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  if (distance > 0 && distance < 30) {
    digitalWrite(LED_PIN, HIGH);   // 点亮LED
  } else {
    digitalWrite(LED_PIN, LOW);    // 熄灭LED
  }
  delay(200);
}
```

## 开发环境

- **IDE：** Arduino IDE 2.x
- **开发板支持包：** ESP32 Arduino
- **开发板选择：** ESP32C3 Dev Module
- **串口波特率：** 115200

### 环境配置步骤

1. 安装 Arduino IDE 2.x
2. 文件 → 首首选项 → 附加开发板管理器网址：
   ```
   https://dl.espressif.com/dl/package_esp32_index.json
   ```
3. 工具 → 开发板 → 开发板管理器 → 搜索 "esp32" → 安装
4. 工具 → 开发板 → ESP32 Arduino → ESP32C3 Dev Module
5. 工具 → Port → 选择对应串口

### 上传代码方法

ESP32-C3 进入下载模式：
1. **按住 BOOT 键**
2. 点击 Arduino IDE 的上传按钮
3. 等待出现 "Connecting..." 或进度条开始
4. **松开 BOOT 键**

### 周六 09:50 · 头脑风暴 & 分工

确定做"超声波+LED"报警器，解决宿舍夜间下床撞到桌角的问题。分工：
- 吴天鹏：主代码、串口调试、系统集成
- 符永儒：硬件接线、电路调试
- 司淼清：3D建模、外壳设计
- 吴辉：测试、文档、物料管理

### 周六 10:30 · 🔥 踩坑1：ESP32-C3 引脚选错

拿到开发板后发现不是标准 ESP32 DevKit，而是 ESP32-C3 SuperMini。上网查 datasheet，发现 GPIO 编号与丝印标注不完全一致。

**问题：** 最初以为 Trig 接 GPIO2、Echo 接 GPIO3，结果烧录后串口无输出。

**原因：** GPIO2 是 boot strapping 引脚，不能随便用。

**解决：** 改用 GPIO4/5 后正常。

### 周六 11:00 · 🔥 踩坑2：烧录卡在 "Connecting...."

点击 Arduino IDE 上传，卡在 "Connecting..." 不动。

**原因：** ESP32-C3 需要手动进入下载模式。

**解决：** 按住 BOOT 键 → 点上传 → 等出现 "Connecting..." 后松开 BOOT。之前不知道这个操作，白耗了 20 分钟。

### 周六 11:40 · 🔥 踩坑3：串口监视器乱码

上传成功后打开串口监视器，全是乱码。

**原因：** 代码写的是 115200，但串口监视器默认是 9600。

**解决：** 改为 115200 后正常显示。

### 周六 13:30 · 硬件搭建

符永儒开始接线。按照查好的引脚图，Trig→GPIO4, Echo→GPIO5, LED→GPIO6。杜邦线直连，不用面包板。

### 周六 13:50 · 🔥 踩坑4：HC-SR04 的 5V/3.3V 问题

HC-SR04 的 Echo 引脚输出 5V 高电平，但 ESP32-C3 的 GPIO 只耐受 3.3V。

**问题：** 测试时发现偶尔会读到异常大的数值（>1000cm）。

**解决：** 在 Echo 和 GPIO5 之间加了一个简单的分压电路（1kΩ + 2kΩ），把 5V 降到 3.3V。后来发现其实直接接也能跑，但为了板子安全还是保留了分压。

### 周六 14:20 · 🔥 踩坑5：测距数据跳变严重

串口输出的距离值每隔几秒就会跳变一次，比如正常是 25cm，突然蹦出一个 400cm 或 0cm。

**原因：** 超声波在光滑表面（如玻璃、白墙）反射不稳定，偶尔收不到回波。pulseIn() 超时返回 0，导致计算出距离 0。

**解决：** 加了一个简单的滤波 —— 连续读 5 次取中位数，同时过滤掉 0 和 >400cm 的异常值。

### 周六 15:00 · 🔥 踩坑6：LED 烧毁事故

测试时手靠近传感器，LED 亮了一下就灭了，之后再也点不亮。拆下来一看，LED 内部已经发黑。

**原因：** 第一次接线时忘记串联电阻，LED 直接接了 GPIO6（3.3V）。虽然电压不高，但电流过大还是烧了。

**教训：** 所有 LED 必须串联限流电阻！220Ω 电阻串联后，电流约 15mA，在安全范围内。

### 周六 15:40 · ✅ 里程碑：核心功能跑通

更换 LED + 串联电阻后，功能终于跑通：手靠近 30cm 以内 LED 亮，离开后 LED 灭。串口数据稳定，反应延迟约 200ms。

### 周六 16:30 · 阈值调试

吴辉负责测试不同距离下的触发效果。发现 30cm 是最佳阈值 —— 太近（如 10cm）反应太晚，太远（如 50cm）误触发多。最终确定 30cm。

### 周六 17:00 · 串口数据可视化

吴天鹏在串口监视器里加了简单的柱状图显示，方便演示时直观展示距离变化。

### 周六 19:00 · 联调稳定版

全部代码整合，阈值 30cm，反应灵敏。决定不加蜂鸣器（物资有限，且安静更适合宿舍场景），用更简洁的 LED 方案，满足"至少1个传感器+1个执行器"要求。

### 周日 09:00 · 外壳设计启动

司淼清开始用 Fusion 360 建模。设计参数：

第一版外壳打印出来，HC-SR04 传感器塞不进去！

## 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 上传代码卡在 "Connecting..." | ESP32-C3 未进入下载模式 | 按住 BOOT 键 → 点上传 → 松开 BOOT |
| 串口乱码 | 波特率不匹配 | 串口监视器波特率设为 115200 |
| 测距数据跳变 | 超声波反射不稳定 | 代码中使用中位数滤波 |
| LED 不亮 | 忘记串联电阻或 LED 烧毁 | 检查接线，更换 LED，串联 220Ω 电阻 |
| GPIO2 无响应 | GPIO2 是 boot strapping 引脚 | 改用其他 GPIO（如 4/5/6） |
| 测距值为 0 | pulseIn() 超时 | 代码中过滤 0 值，返回最大距离 |
| 外壳塞不进去 | 建模尺寸偏小 | 重新测量实物，每边留 1mm 余量 |
