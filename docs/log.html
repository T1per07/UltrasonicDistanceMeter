核心代码

float measureDistance() {
    digitalWrite(TRIG_PIN, LOW);
    delayMicroseconds(2);
    digitalWrite(TRIG_PIN, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG_PIN, LOW);

    long duration = pulseIn(ECHO_PIN, HIGH, 30000);
    if (duration == 0) return -1;

    float distance = duration * 0.034 / 2;
    return (distance > MAX_DISTANCE) ? -1 : distance;
}
                
void alertFeedback(float distance) {
    if (distance <= DANGER_DISTANCE) {
        digitalWrite(LED_PIN, HIGH);
        tone(BUZZER_PIN, 1000, 100);
        delay(150);
        tone(BUZZER_PIN, 1500, 100);
        delay(150);
    } else if (distance <= WARNING_DISTANCE) {
        digitalWrite(LED_PIN, HIGH);
        tone(BUZZER_PIN, 800, 200);
        delay(300);
    } else {
        digitalWrite(BUZZER_PIN, LOW);
        digitalWrite(LED_PIN, LOW);
    }
}

设计思维

问题定义

在日常生活中，人们经常需要快速测量距离，但传统卷尺使用不便，且难以测量远距离或难以触及的位置。我们希望设计一款便携、直观的测距设备。

解决方案

利用超声波测距技术，结合 ESP32-C3 的低功耗特性和 OLED 显示屏的直观显示，打造一款能够实时显示距离并提供声光报警的便携式测距仪。

创新点

  • 分级报警系统（安全/警告/危险）
  • 中值滤波算法提升测量稳定性
  • 3D 打印定制外壳，美观便携
  • 低功耗设计，适合长时间使用

应用场景

  • 室内装修测量
  • 工业生产中的距离监测
  • 智能小车避障
  • 盲人辅助导航
  • 智能垃圾桶感应开盖

Reflections - 遇到的 Bug 与解决方案

  • Bug 1: 超声波读数不稳定

    现象：HC-SR04 返回的距离值在实际距离附近大幅跳动，误差超过 10cm。

    原因：单次测量受环境噪声影响大，超声波反射不稳定。

    解决：实现中值滤波算法，连续采集 10 个数据，取中位数作为有效值。同时增加超时处理，避免无效读数。

  • Bug 2: OLED 显示花屏

    现象：SSD1306 显示屏出现乱码或全白屏。

    原因：I2C 总线地址配置错误，实际地址为 0x3C 而非默认的 0x3D。

    解决：使用 I2C Scanner 程序扫描总线，确认正确地址后修改代码。

  • Bug 3: 蜂鸣器不响

    现象：代码逻辑正确，但蜂鸣器无声音输出。

    原因：ESP32-C3 的 tone() 函数与 Arduino 标准库行为不同，需要指定通道。

    解决：改用 ledcSetup() 和 ledcWrite() 函数，配置 PWM 通道驱动蜂鸣器。

  • Bug 4: 外壳尺寸不匹配

    现象：3D 打印的外壳无法容纳传感器和显示屏。

    原因：建模时未考虑接线空间和公差。

    解决：重新测量实际组件尺寸，每边增加 2mm 余量，添加走线槽设计。
