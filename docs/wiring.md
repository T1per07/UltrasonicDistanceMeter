# 接线说明

## ESP32-C3 与超声波传感器 HC-SR04 连接

```
ESP32-C3          HC-SR04
─────────────────────────
GPIO 4    ───►    Trig
GPIO 5    ◄───    Echo
5V / VIN  ───►    VCC
GND       ───►    GND
```

## ESP32-C3 与 LED 连接

```
ESP32-C3          组件
─────────────────────────
GPIO 6    ───►    220Ω电阻 ───► LED正极（长脚）
GND       ───►    LED负极（短脚）
```

## 接线要点

1. **杜邦线直连**：所有连接使用母对公杜邦线，无需面包板
2. **LED 必须串联电阻**：220Ω 电阻串联在 GPIO 和 LED 正极之间，防止烧毁
3. **超声波传感器供电**：VCC 接 5V 或 VIN（不能接 3.3V，传感器工作电压为 5V）
4. **Echo 引脚注意**：HC-SR04 的 Echo 输出 5V，ESP32-C3 GPIO 耐受 3.3V。实测直接接可以工作，但为安全起见可加分压电路

## 分压电路（可选）

如果担心 5V 损坏 GPIO，可在 Echo 和 GPIO5 之间加分压：

```
Echo ──── 1kΩ ──┬── GPIO5
                 │
                2kΩ
                 │
                GND
```

分压后电压：5V × 2kΩ / (1kΩ + 2kΩ) ≈ 3.3V

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 上传代码卡在 "Connecting..." | ESP32-C3 未进入下载模式 | 按住 BOOT 键 → 点上传 → 松开 BOOT |
| 串口乱码 | 波特率不匹配 | 串口监视器波特率设为 115200 |
| 测距数据跳变 | 超声波反射不稳定 | 代码中使用中位数滤波 |
| LED 不亮 | 忘记串联电阻或 LED 烧毁 | 检查接线，更换 LED |
| GPIO2 无响应 | GPIO2 是 boot strapping 引脚 | 改用其他 GPIO（如 4/5/6） |
